# 🗺️ Manhattan Dynamic Soft Routes Visualizer
### Interactive 24-Hour Comparative Graphical Interface: GCT-LM (NLP) vs. TopoScan

This web application provides an interactive, side-by-side geographical visualization of the learned dynamic soft routes generated by the **GCT-LM Trajectory Language Model** versus the **TopoScan Heuristic Baseline** across all 48 time bins of the 24-hour diurnal cycle on Manhattan's road network.

---

## 🌟 Key Visualizer Features

1. **Synchronized Dual-Map Split Screen:**
   - **Left Pane (GCT-LM NLP):** Displays the 8 primary arterial flow corridors (e.g., Broadway, 5th Ave, FDR Drive, West Side Highway) color-coded with vibrant neon palettes and directional sequence edges.
   - **Right Pane (TopoScan Baseline):** Displays the heuristic topological cluster web (up to 2,331 geometric paths) rendered in translucent goldenrod lines.
   - Panning and zooming either map automatically synchronizes both views in real time.

2. **24-Hour Time Scrubber & Auto-Play Animation:**
   - Drag the slider through all **48 discrete 30-minute time bins** (`Bin 00: 00:00–00:30` to `Bin 47: 23:30–24:00`).
   - Hit **Play (▶)** to watch the soft routes dynamically adjust and morph through the morning rush, midday lull, evening rush, and late-night surges.
   - Adjustable playback speeds (1x, 2x, 4x).

3. **Model Structure & Comparative HUD:**
   - Real-time structural metrics comparison for each 30-minute time bin:
     - **Active Soft Route Trunks:** 8 canonical arterial trunks for GCT-LM vs. 2,331 geometric paths for TopoScan.
     - **Mean Route Length:** ~41 arterial edges for GCT-LM vs. ~54.6 edges for TopoScan micro-paths.
     - **Corridor Geometry:** Continuous island-wide arterial corridors (Broadway, 5th Ave, FDR Drive, West Side Highway) vs. highly fragmented local micro-clusters.
     - **Spatial Scope:** Long-range corridor connectivity vs. local neighborhood dead-ends.

4. **Trunk Inspector & Focus:**
   - Click or hover over any of the 8 GCT-LM arterial corridors in the right-hand drawer to highlight that route on the map, dim other paths, and inspect its edge sequence and length.
   - Adjust TopoScan display density (`Top 25`, `Top 50`, `Top 100`, `Top 200`, `All`).

5. **Zero External Web Dependencies & GitHub-Friendly:**
   - Uses Python's built-in `http.server.ThreadingHTTPServer` (no Flask, FastAPI, or npm installations required).
   - Serves edge coordinates dynamically from the local SUMO network file without bloating git with 100+ MB GeoJSON files.
